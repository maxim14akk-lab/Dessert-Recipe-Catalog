🍰 Dessert Recipe Catalog — коллекция сладких рецептов

> «Сладкая жизнь начинается с хорошего рецепта»

**Dessert Recipe Catalog** — это набор консольных приложений для ведения каталога рецептов десертов.  
Программа позволяет добавлять, искать, редактировать и удалять рецепты, а также экспортировать их в JSON и CSV.

## 🚀 Особенности
- 📝 Добавление рецептов: название, категория, ингредиенты, инструкция, время приготовления, сложность.
- 🔍 Поиск по названию, ингредиентам или категории.
- ⭐ Оценка рецептов (1-5 звёзд).
- 📋 Фильтрация по категории, сложности, времени приготовления.
- 📊 Статистика: количество рецептов, средняя оценка, популярные категории.
- 💾 Автосохранение в JSON-файл (`recipes.json`).
- 📤 Экспорт в CSV и JSON.
- 🎨 Цветной вывод в терминале.

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости (в основном стандартные библиотеки).

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | стандартная библиотека               | `python recipe_catalog.py`              |
| Go         | стандартная библиотека               | `go run recipe_catalog.go`              |
| JavaScript | Node.js, `fs`, `readline`            | `node recipe_catalog.js`                |
| Java       | стандартная библиотека               | `javac recipe_catalog.java && java recipe_catalog` |
| C#         | .NET (или mono)                      | `dotnet run`                            |
| Rust       | `serde`, `serde_json`, `chrono`      | `cargo run`                             |
| Ruby       | `json` (стандартная)                 | `ruby recipe_catalog.rb`                |
| PHP        | стандартная библиотека               | `php recipe_catalog.php`                |
